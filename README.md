# SortTrack

Техническое задание и исходная точка постепенного рефакторинга находятся в [TZ_REFACTORING.md](./TZ_REFACTORING.md) и [docs/refactoring/R0_BASELINE.md](./docs/refactoring/R0_BASELINE.md). Рефакторинг сохраняет существующий Tauri/Rust/React стек, схему данных и гарантии безопасности файловых операций.

SortTrack — локальный организатор музыкальной библиотеки MP3/FLAC для Windows.

## Текущий этап

Реализуется MVP 1.0 и поэтапный рефакторинг. Этапы R0–R2 завершены: зафиксирована страховочная база, frontend разделён на feature boundaries, а gateway — на предметные ports и отдельные demo/Tauri adapters. Отчёты: [R1](./docs/refactoring/R1_FRONTEND_BOUNDARIES.md), [R2](./docs/refactoring/R2_GATEWAY_CONTRACTS.md). Текущий путь до релиза и все ручные проверки зафиксированы в [протоколе приёмки MVP](./docs/MVP_ACCEPTANCE.md); требования к безопасной тестовой медиатеке находятся в [MVP_TEST_CORPUS.md](./docs/MVP_TEST_CORPUS.md).

Сейчас в репозитории находится первый рабочий desktop-срез:

- Tauri 2 + Rust backend;
- SQLite repository и первая миграция;
- безопасный рекурсивный поиск MP3/FLAC без перехода по symlink;
- чтение реальных тегов MP3/FLAC, длительности, битрейта, частоты дискретизации,
  разрядности и числа каналов;
- импорт BPM и музыкальной тональности с автоматическим переводом в Camelot notation;
- изоляция повреждённых файлов: они остаются видимыми и не прерывают сканирование;
- двухэтапное добавление папки: read-only оценка количества, выбор обхода подпапок и безопасных относительных исключений, затем отдельное подтверждение scan;
- список сохранённых папок библиотеки в настройках: путь, статус, последняя проверка, подпапки и исключения; повторный scan начинается с безопасного preview;
- обратимое отключение и подключение библиотечного корня без удаления треков или изменения MP3/FLAC; при подключении проверяется доступность каталога;
- автоматическая проверка доступности активных библиотечных папок при открытии настроек без обхода музыки и без автоматического подключения отключённых корней;
- двухэтапное удаление только регистрации отключённого корня с сохранением треков, истории и аудиофайлов; повторное добавление прикрепляет неизменённые файлы без дублей;
- живой прогресс индексирования с паузой, продолжением и безопасной отменой между файлами;
- фактическая скорость scan, ETA без времени паузы и полный локальный отчёт по проблемным путям;
- диалог выбора локальной папки;
- библиотека и входящие треки из реальной локальной БД;
- поиск и фильтрация;
- расширенные совместимые фильтры библиотеки по BPM, минимальному рейтингу, Camelot, MP3/FLAC и доступности файла, применяемые до пагинации;
- плеерный UI;
- воспроизведение локальных MP3/FLAC с паузой, перемоткой, громкостью и очередью;
- waveform текущего трека с переходом к выбранной позиции по клику;
- shuffle, repeat-all/repeat-one, mute, безопасная очередь текущей страницы и горячие клавиши плеера;
- переход из индикатора очереди к проигрываемому треку с вычислением нужной страницы непосредственно в SQLite;
- локальный дисковый waveform-кэш с проверкой состояния исходного файла без повторного чтения всего аудио в WebView;
- hover-time, точный seek и масштаб waveform ×1/×2/×4 с автоматическим переходом между окнами;
- чтение embedded cover из MP3/FLAC, ленивое отображение в библиотеке, плейлистах и плеере с локальным проверяемым кэшем;
- выдача WebView доступа только к конкретному проверенному файлу на время работы;
- несколько одновременно открытых ручных плейлистов;
- создание и переименование плейлистов, изменение порядка и перенос треков drag-and-drop;
- динамические автоплейлисты по жанру и диапазону BPM с лимитом и сортировкой; состав пересчитывается из SQLite и защищён от ручного изменения;
- фиксация текущего результата автоплейлиста как отдельного редактируемого снимка, который можно экспортировать и безопасно копировать;
- изменение жанра, BPM-диапазона, лимита и сортировки существующего автоплейлиста с защитой от конфликтующих правок;
- дополнительные условия автоплейлистов по подтверждённому поджанру, минимальному рейтингу и Camelot-тональности;
- интерактивный рейтинг 0–5 в строке трека; изменение сразу пересчитывает зависящие от него автоплейлисты и сохраняется в истории;
- просмотр последних изменений рейтинга и массовая установка/сброс оценки для выбранных треков с итоговым отчётом;
- подтверждаемое удаление только плейлиста с защитой от изменившегося состава; треки и MP3/FLAC сохраняются;
- предварительный план безопасного копирования файлов плейлиста;
- разрешение конфликтов без перезаписи: пропуск или новое имя;
- копирование через временный файл с проверкой размера и SHA-256;
- локальный отчёт по каждому скопированному, использованному или пропущенному файлу;
- постоянный журнал состояний Copy с неизменяемыми размером/временем источника и подтверждённым решением конфликта;
- обнаружение незавершённого Copy после перезапуска, проверка уже созданных файлов по SHA-256 и безопасное повторное копирование;
- безопасная отмена восстановления удаляет только служебный файл, чей путь строго принадлежит конкретной операции SortTrack;
- экспорт плейлистов в детерминированный UTF-8 M3U8 с абсолютными или относительными путями;
- экспорт отдельных Traktor NML 19 для профилей Traktor Pro 3 и Traktor Pro 4 без изменения `collection.nml`;
- preview порядка, путей и отсутствующих файлов перед атомарной записью экспорта без перезаписи;
- поиск точных дубликатов по полному SHA-256 без удаления пользовательских файлов;
- кэш хэшей с проверкой размера, времени изменения и физической идентичности файла;
- группы дубликатов с безопасной рекомендацией предпочтительного экземпляра;
- одиночный редактор основных тегов MP3/FLAC с обязательным предварительным просмотром;
- запись тегов в отдельную копию, повторное чтение и атомарная замена исходного файла;
- защита от внешнего изменения между preview и подтверждением;
- полная история подтверждённых изменений и подготовка восстановления прежней версии;
- массовое редактирование до 1000 MP3/FLAC за одну операцию: изменяются только явно отмеченные поля, а пустое отмеченное поле удаляет соответствующий тег;
- обязательный preview массовой операции, независимая безопасная запись каждого файла и итоговый отчёт по сохранённым, пропущенным и ошибочным трекам;
- локальный анализ BPM и музыкальной тональности непосредственно из MP3/FLAC без отправки аудио в интернет;
- постоянная очередь анализа до 1000 треков с прогрессом по файлам и байтам, паузой, отменой и восстановлением после перезапуска;
- хранение рассчитанных BPM, тональности, Camelot, оценок уверенности и версии алгоритма отдельно от пользовательских тегов;
- автоматический сброс результатов анализа при изменении исходного файла;
- версионируемая жанровая таксономия и aliases;
- локальный жанровый помощник с тремя объяснимыми кандидатами по тегу, пути, имени файла и BPM;
- score, версия алгоритма и использованные сигналы сохраняются отдельно от подтверждённого жанра;
- ручное подтверждение, история решений, фиксация результата и явное снятие фиксации без автоматической записи genre tag;
- последовательная очередь ручной жанровой разметки с прогрессом, безопасным пропуском и клавишами 1/2/3, L и S;
- локальная резервная копия SQLite с manifest, integrity check и SHA-256 без копирования аудиофайлов;
- двухэтапное восстановление backup с preview, safety-копией, проверкой схемы, перезапуском и crash-safe rollback;
- повторное сканирование с безопасным статусом missing, восстановлением вернувшихся файлов и распознаванием перемещений по file identity;
- ручной поиск и безопасная перепривязка отсутствующего MP3/FLAC с preview, повторной проверкой и сохранением плейлистов, жанра и истории трека;
- серверная пагинация по 100 треков, SQLite-фильтрация и сортировка без загрузки всей коллекции в интерфейс;
- настраиваемая таблица библиотеки: видимость, порядок и ширина столбцов сохраняются локально в SQLite и входят в backup;
- синхронизируемый локальный FTS5-индекс для поиска по тегам, имени файла, пути и комментариям;
- аудит validation dataset только по зафиксированным ручным жанрам с показом баланса классов и отсутствующих жанров;
- атомарный экспорт локального JSON manifest без копирования аудио и без перезаписи существующего файла;
- проверяемый SHA-256 кэш, схлопывание повторов и детерминированное разбиение 70/15/15 по группам записей;
- локальное извлечение 25 ритмических и спектральных признаков из репрезентативных нетихих окон MP3/FLAC;
- кэш аудиопризнаков по версии extractor и снимку файла с автоматическим сбросом при изменении файла;
- измеримый nearest-centroid baseline: обучение только на train, настройка score на calibration и финальная оценка только на test;
- отчёт top-1 accuracy, ошибок извлечения, per-class recall и confusion matrix без объявления модели готовой ниже порога 70%;
- планировщик безопасного копирования без перезаписи;
- автоматические тесты критичных правил.

В браузерном режиме используются демонстрационные данные. В Tauri-сборке интерфейс подключается к локальной SQLite БД через проверяемый `LibraryGateway`.

## Локальная диагностика

В настройках можно предварительно просмотреть состав диагностического пакета, сохранить его вручную как JSON, открыть папку логов или удалить принадлежащие SortTrack диагностические файлы после явного подтверждения. По умолчанию локальные пути маскируются. Музыкальные файлы, SQLite-база, плейлисты и музыкальные метаданные в пакет не включаются; автоматическая отправка по сети отсутствует.

Логи хранятся в `logs` внутри активного профиля данных, crash reports — в `crashes`. JSONL-логи ротируются при размере 2 МБ, сохраняется не более пяти файлов и записи старше 30 дней удаляются.

## Команды

```text
npm install
npm run dev
npm test
npm run build
npm run desktop:dev
npm run desktop:build
npm run desktop:portable
npm run release:metadata
npm run release:build
```

`release:metadata` работает без сети после подготовки дистрибутивов и создаёт в общем каталоге релиза SPDX 2.3 SBOM, полный CSV-реестр заявленных лицензий, release manifest и `SHA256SUMS.txt`.

`release:build` формирует общий каталог `src-tauri/target/release/bundle/release` с установленной и portable-версиями. Portable хранит базу и кэши только в папке `data` рядом с распакованным приложением; режим и фактический путь видны в настройках.

Процесс локального выпуска и GitHub CI описан в [docs/RELEASE_PROCESS.md](./docs/RELEASE_PROCESS.md). Текущая Windows-сборка не имеет коммерческой code-signing подписи и может вызвать предупреждение SmartScreen; автоматические обновления отключены до появления подписанного update manifest.

Для desktop-сборки требуются Rust stable MSVC, Visual Studio C++ Build Tools и WebView2 Runtime.

Подробные требования находятся в [TZ.md](./TZ.md).
