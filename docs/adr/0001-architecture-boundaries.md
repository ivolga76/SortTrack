# ADR 0001: Границы первого вертикального среза

**Статус:** принято  
**Дата:** 2026-08-08

## Решение

UI зависит от интерфейса `LibraryGateway`, а не от Tauri IPC напрямую. Демонстрационный gateway позволяет разрабатывать и проверять интерфейс без Rust toolchain. Production gateway будет адаптером Tauri-команд.

Доменная логика, не требующая файловой системы, реализуется на TypeScript и покрывается быстрыми unit-тестами. Критические файловые переходы повторно валидируются и исполняются только Rust backend.

## Следствия

- UI можно проверять в браузере и Tauri WebView;
- backend можно менять без переписывания компонентов;
- правила планирования Copy тестируются независимо;
- TypeScript никогда не получает право самостоятельно копировать файлы;
- Rust остается источником истины для SQLite и физической файловой системы.

## Следующий ADR

После установки Rust toolchain необходимо выбрать SQLite crate, connection model и migration runner на основании нагрузочного прототипа.
