SortTrack Portable 0.1.0
========================

1. Полностью распакуйте архив в отдельную папку на внутреннем диске.
2. Не запускайте SortTrack.exe непосредственно из ZIP-архива.
3. Убедитесь, что у вашей учётной записи есть право записи в выбранную папку.
4. Запустите SortTrack.exe. База, кэши и остальные локальные данные будут созданы в подпапке data.

Файл .sorttrack-portable является обязательным маркером portable-режима. Не удаляйте его и не переносите один SortTrack.exe отдельно: без маркера приложение использует профиль установленной версии в %LOCALAPPDATA%.

Portable- и installed-версии не используют общую базу. Музыкальные MP3/FLAC не копируются в data и остаются в выбранных вами папках.

Полный текст основной лицензии GNU AGPL-3.0 находится в файле LICENSE рядом с приложением. Уведомления о сторонних компонентах находятся в THIRD_PARTY_NOTICES.md.

Если папка недоступна для записи, SortTrack завершит запуск с ошибкой до открытия SQLite. Выберите обычную пользовательскую папку, но не Program Files и не защищённый системный каталог.
